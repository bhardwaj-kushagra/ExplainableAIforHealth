## 🔧 Where to Make Changes

### 1. Swapping Synthetic Data with Real Hospital Data

**Current:** System uses `data_synthetic/generate_synthetic.py` for demonstration  
**Production:** Replace with de-identified hospital admissions CSV  

#### Step-by-Step:

**A. Prepare Real Data CSV**

Format must match this schema:
```csv
date,region_id,admissions,temp_mean_c,temp_min_c,temp_max_c,relative_humidity_pct,dew_point_c,pm25_ugm3,day_of_week,is_holiday,season
2020-01-01,R1,8,15.2,12.0,18.5,60.0,8.5,25.0,2,1,Winter
2020-01-02,R1,12,16.8,13.5,20.1,55.0,9.2,28.0,3,0,Winter
```

**Column Specifications:**
- `date`: YYYY-MM-DD format
- `region_id`: String identifier (e.g., "R1", "NYC", "LA")
- `admissions`: Integer count of cardiovascular emergency admissions
- `temp_mean_c`, `temp_min_c`, `temp_max_c`: Float, degrees Celsius
- `relative_humidity_pct`: Float, 0-100
- `dew_point_c`: Float, degrees Celsius
- `pm25_ugm3`: Float, micrograms per cubic meter
- `day_of_week`: Integer, 0=Monday, 6=Sunday
- `is_holiday`: Boolean, 0 or 1
- `season`: String, one of: "Winter", "Spring", "Summer", "Fall"

**B. Place File in Repository**
```
mkdir -p data_raw
cp /path/to/hospital_admissions.csv data_raw/hospital_admissions.csv
```

**C. Update Ingestion Script**

Edit `src/ingest.py` line 85:
```python
# Change from:
csv_path = "data_synthetic/synthetic_data.csv"

# To:
csv_path = "data_raw/hospital_admissions.csv"
```

**D. Update .gitignore**

Add to `.gitignore` to prevent committing sensitive data:
```
data_raw/
*.csv
outputs/data_provenance.json
```

**E. Retrain Models**
```powershell
make preprocess  # Reprocess with real data
make train       # Retrain XGBoost model
pytest tests/    # Validate results
```

**F. Verify Performance**

Check `outputs/metrics.json`:
- `test_r2` should be > 0.70 (acceptable)
- `test_mae` should be < 2.0 admissions/day (reasonable)

If performance is poor, adjust model hyperparameters in `src/models/xgb_train.py` lines 50-57.

### 2. Changing Forecast Data Sources

**Current:** API uses static forecast input from POST requests  
**Production:** Integrate with real-time weather APIs  

#### Option A: National Weather Service (NWS) API

**Implementation:**

1. **Create forecast fetcher function** in `src/api/forecast_fetcher.py`:
```python
import requests
from typing import List
from .schemas import ForecastDay

def fetch_nws_forecast(latitude: float, longitude: float, days: int = 5) -> List[ForecastDay]:
    """
    Fetch weather forecast from National Weather Service API.
    
    Parameters
    ----------
    latitude : float
        Latitude of region (e.g., 40.7128 for NYC)
    longitude : float
        Longitude of region (e.g., -74.0060 for NYC)
    days : int
        Number of days to forecast (default 5)
    
    Returns
    -------
    List[ForecastDay]
        Parsed forecast data matching API schema
    """
    # Get gridpoint endpoint
    points_url = f"https://api.weather.gov/points/{latitude},{longitude}"
    points_response = requests.get(points_url, headers={"User-Agent": "CVD Health App"})
    points_response.raise_for_status()
    forecast_url = points_response.json()["properties"]["forecast"]
    
    # Get forecast
    forecast_response = requests.get(forecast_url, headers={"User-Agent": "CVD Health App"})
    forecast_response.raise_for_status()
    periods = forecast_response.json()["properties"]["periods"][:days*2]  # 12-hour periods
    
    # Parse and aggregate to daily
    daily_forecasts = []
    for i in range(0, len(periods), 2):
        day_period = periods[i]
        night_period = periods[i+1] if i+1 < len(periods) else periods[i]
        
        forecast_day = ForecastDay(
            date=day_period["startTime"].split("T")[0],
            temp_mean_c=convert_f_to_c((day_period["temperature"] + night_period["temperature"]) / 2),
            temp_max_c=convert_f_to_c(day_period["temperature"]),
            temp_min_c=convert_f_to_c(night_period["temperature"]),
            relative_humidity_pct=extract_humidity(day_period["detailedForecast"]),
            # Estimate dew point from temp and humidity
            dew_point_c=calculate_dew_point(temp_mean_c, relative_humidity_pct),
            # PM2.5 requires separate API (see Option B)
            pm25_ugm3=25.0,  # Default placeholder
            day_of_week=datetime.strptime(date, "%Y-%m-%d").weekday(),
            is_holiday=check_holiday(date),
            season=get_season(date)
        )
        daily_forecasts.append(forecast_day)
    
    return daily_forecasts[:days]

def convert_f_to_c(fahrenheit: float) -> float:
    return (fahrenheit - 32) * 5/9

def calculate_dew_point(temp_c: float, rh_pct: float) -> float:
    """Magnus formula approximation"""
    a, b = 17.27, 237.7
    alpha = ((a * temp_c) / (b + temp_c)) + np.log(rh_pct / 100.0)
    return (b * alpha) / (a - alpha)
```

```python
def fetch_airnow_pm25(latitude: float, longitude: float, date: str) -> float:
    url = f"https://www.airnowapi.org/aq/forecast/latLong/"
    params = {
        "format": "application/json",
        "latitude": latitude,
        "longitude": longitude,
        "date": date,
        "distance": 25,  # Miles
        "API_KEY": os.getenv("AIRNOW_API_KEY")
    }
    response = requests.get(url, params=params)
    response.raise_for_status()
    data = response.json()
    
    # Extract PM2.5 value
    for forecast in data:
        if forecast["ParameterName"] == "PM2.5":
            return forecast["AQI"]  # Convert AQI to µg/m³ if needed
    
    return 25.0  # Default if not available
```

### 3. Modifying Model Hyperparameters

**File:** `src/models/xgb_train.py` lines 50-57

**Current Configuration:**
```python
xgb_model = XGBRegressor(
    objective='count:poisson',   # For count data
    n_estimators=300,             # Number of trees
    max_depth=5,                  # Tree depth (prevent overfitting)
    learning_rate=0.05,           # Shrinkage rate
    subsample=0.8,                # Row sampling
    colsample_bytree=0.8,         # Column sampling
    random_state=42               # Reproducibility
)
```

**Tuning Guidelines:**

- **Underfitting (R² < 0.70):** Increase `n_estimators` to 500, `max_depth` to 7
- **Overfitting (train R² >> test R²):** Decrease `max_depth` to 3, increase `subsample` to 0.9
- **Faster training:** Decrease `n_estimators` to 200, increase `learning_rate` to 0.1
- **Better calibration:** Keep `objective='count:poisson'` for count data

**Hyperparameter Search:**

Add to `xgb_train.py` after line 57:
```python
from sklearn.model_selection import RandomizedSearchCV

param_grid = {
    'n_estimators': [200, 300, 500],

    'learning_rate': [0.01, 0.05, 0.1],
    'subsample': [0.7, 0.8, 0.9]
}

    XGBRegressor(objective='count:poisson', random_state=42),
```

## 🚨 Troubleshooting

### Issue: Model Performance Degraded

**Symptoms:** R² drops below 0.70, MAE increases significantly  
**Causes:**
1. Data drift (climate patterns changing)
2. Sensor recalibration (weather station changes)
3. Coding changes (ICD-10 updates)

**Resolution:**
```powershell
# Retrain model with recent data
python src/models/xgb_train.py

# Check SHAP values for new patterns
python src/explainers.py

# Validate on holdout set
pytest tests/test_model.py
```

### Issue: API Returning 503 Errors

**Symptoms:** `/predict` endpoint fails with "Model not loaded"  
**Cause:** Model file missing or corrupted  

**Resolution:**
```powershell
# Verify model exists
ls outputs/xgb_model.joblib

# Retrain if missing
python src/models/xgb_train.py

# Restart API
make run-api
```

### Issue: Dashboard Not Showing Visualizations

**Symptoms:** Blank pages in Streamlit  
**Cause:** Missing output files  

**Resolution:**
```powershell
# Regenerate all outputs
make viz

# Check file existence
ls outputs/*.png outputs/*.html

# Restart dashboard
make run-dashboard
```

### Issue: Docker Build Fails

**Symptoms:** Error installing geopandas  
**Cause:** Missing system dependencies  

**Resolution:**
```dockerfile
# Add to Dockerfile before RUN pip install
RUN apt-get update && apt-get install -y \
    gcc g++ libgdal-dev libgeos-dev libproj-dev \
    && rm -rf /var/lib/apt/lists/*
```
